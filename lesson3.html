Top Risky Behaviours to Avoid

These habits make you an easy target

  • 🔐
    Password Reuse Using the same password across multiple accounts — if one site is breached, all accounts are compromised
  • 📍
    Oversharing Personal Info Posting vacation dates, home addresses, birth dates, or family details publicly
  • 🔄
    Ignoring Software Updates Delaying security patches leaves known vulnerabilities unpatched for attackers to exploit
  • 📎
    Clicking Unknown Links/Attachments Opening unexpected files or links without verifying the sender first
  • 📡
    Using Public Wi-Fi Without Protection Accessing banking or sensitive accounts on unencrypted public networks
  • 📸
    Sharing Sensitive Documents Online Posting photos of IDs, tickets, or confidential work documents
✅

Safe Alternatives

Build these security habits instead

  • 🔐
    Use a Password Manager Generate and store unique passwords for every account
  • 📍
    Share Vacation Photos AFTER Returning Post memories after you're back home, not during the trip
  • 🔄
    Enable Automatic Updates Set devices to install security patches automatically
  • 📎
    Verify Before Clicking Hover, check sender, and verify legitimacy first
  • 📡
    Use a VPN on Public Wi-Fi Encrypt your traffic on untrusted networks
  • 📸
    Blur Sensitive Info Before Sharing Hide addresses, ticket numbers, and IDs before posting

Daily Security Habits to Adopt

Small changes that make a big difference

🔐
Unique passwords everywhere Use a password manager to generate strong, unique passwords for every account
🔄
Automatic updates ON Enable auto-updates for OS, browsers, and apps — never delay security patches
📍
Think before you post Share vacation photos AFTER you return, not during the trip

Glossary of Terms

Key concepts explained — click to expand

Password Reuse+
Using the same password across multiple accounts. If one service is breached, hackers can access all your accounts using credential stuffing attacks.
Oversharing+
Posting excessive personal information online (vacation dates, home addresses, family details) that can be used for social engineering or physical attacks like burglary.
Credential Stuffing+
Automated attack where hackers use stolen username/password pairs from one breach to try logging into other services.
VPN (Virtual Private Network)+
Encrypts your internet traffic and hides your IP address, essential for safe browsing on public Wi-Fi networks.
Zero-Day Vulnerability+
A software security flaw that is unknown to the vendor. Regular updates patch these as soon as they're discovered.
Digital Footprint+
The trail of data you leave online — posts, comments, likes, and searches. Oversharing expands your digital footprint and attack surface.
